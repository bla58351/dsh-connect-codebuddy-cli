# dsh-connect-codebuddy-cli

在 DeepSeek Harness（DSH）里使用 CodeBuddy 的模型。选中 CodeBuddy 模型发消息时，回答由你本机已经登录的 CodeBuddy CLI 生成——不需要 API key，不需要重新登录，DSH 只负责把对话显示出来。

## 能干什么

- **模型选择器里多一个 CodeBuddy 分组**，里面的模型就是你 CLI 里 `/model` 能看到的那些，倍率也和官方菜单一致。
- **正常聊天**。就像用其他模型一样发消息、传图片、看思考过程；DSH 里装的工具（搜索、执行命令等）也可以勾选给 CodeBuddy 的模型用。
- **模型产出的文件会出现在对话里**，作为可保存的交付物卡片。
- **换模型不丢上下文**。从别的模型切过来，或从 CodeBuddy 切回去，之前聊过的内容都会带上。
- **回退也生效**。用消息旁的 ↶ 按钮回退对话后，CodeBuddy 的模型不会"记得"你刚撤销的内容。
- **保活**。连着聊时不用每次等 CLI 冷启动；停一会儿之后它会自己退掉，不占资源。

## 用之前需要什么

1. 装好 CodeBuddy CLI：`npm install -g @tencent-ai/codebuddy-code`
2. 在终端里运行过一次 `codebuddy` 并完成登录

没有这两样，模型选择器里会出现一行说明，照着做就行。

## 怎么装

把插件文件夹放进/链接到你的 profile，重启 DSH 即可。装好后模型选择器会多出 CodeBuddy 分组；CLI 没就绪时，那一行会告诉你缺什么。

## 在哪里设置

DSH 插件页里的 **CodeBuddy** 卡片，四个标签页：

- **概览**：CLI 版本、登录账号、积分余额。
- **账号**：账号池——准备/登记新账号、单独停用、查看积分与冷却状态。
- **模型**：勾选想在选择器里看到的模型。
- **设置**，三个子页：
  - **后端**：会话保活时长（不想要就设为 0）。
  - **提示词**：模型遵循的行为准则用哪份——DSH 原带的、CodeBuddy 自带的，或你自己写一份；还可以选择把勾选的工具列进提示词，让模型一开始就知道它们存在。
  - **DSH 工具**：勾选允许 CodeBuddy 模型使用的 DSH 工具，每个工具右侧有悬浮提示标，说明该工具的用途。默认只勾了 `present`（让模型产出的文件变成交付物卡片），需要更多就自己加。未做过选择时默认勾选目录里除 DSH 与 CLI 重叠项之外的全部工具（CLI 已有的能力不重复桥接）；保存过一次之后就以你的选择为准。

## 使用须知

- **花的是 CodeBuddy 的积分**，按 CLI 的计费来，DSH 不经手。
- **工具要你点头**：CodeBuddy 模型想写文件、跑命令时，CLI 会停下来问，工具名和本次调用的实际参数一起交给 DSH 审批——你在 DSH 里点"允许"它就执行，点"拒绝"就跳过，模型会看到拒绝理由并继续把话说完。CLI 的权限模式跟着 DSH 的权限设置走，两边不会各说各话；没装审批服务时一律按拒绝处理，不会静默放行。
- **多账号不会偷偷换人**：会话会保持自己的账号绑定，预热和冷启动都一样；只有尚未产生任何输出或工具活动的 429/额度耗尽才会换账号重试，避免重复执行写操作。
- **消息旁的工具卡片是"显示器"**：CodeBuddy 模型执行了某个操作（比如读了文件），卡片展示它做了什么和结果，DSH 不会替它重做一遍。
- **配置修改即时生效**：改完工具勾选或提示词，下一条消息就走新设置，不用重启。
- **图片**：发图没问题（有上限）；模型产出的图片走交付物卡片，这是当前唯一能让它"输出"图片的方式。

想了解内部实现、各种机制为什么这样设计、已知边界与限制，看 [docs/DETAILS.md](docs/DETAILS.md)。

## 参与开发

```bash
npm test        # 语法检查 → 文档一致性 → 离线套件（假 CLI + 假 Host，不调模型不联网）
npm run check   # 只跑语法检查
npm run test:live   # 真实 CLI 套件（会花积分）
```

`npm test` 会先校验文档与代码的一致性（测试数量、目录树、发布清单），文档不同步时测试直接失败——**改代码请同步改文档**；面向 agent 与贡献者的完整协作规则见 [AGENTS.md](AGENTS.md)。

代码按职责分层，`index.js` 只做装配；目录说明与"改动落在哪里"见
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)，行为变化记在 [CHANGELOG.md](CHANGELOG.md)。
